# guizang-game-skill

让 AI 编程助手（Claude Code、Codex 等）从零做出一个能在浏览器里玩的 3D 动作游戏的 Skill。作者：[歸藏](https://x.com/op7418)。

**试玩演示：[雾锁山门](https://op7418.github.io/guizang-game-skill/)**　一个场景、一段小怪遭遇战、一场 Boss 战。电脑和手机都能打开即玩，不用安装。

这个演示从头到尾由 AI 按本 Skill 的流程做出来：模型用 Tripo 生成，图标、题字和配音用即梦生成，配乐用 Suno，音效是 CC0 素材，程序是 three.js。Skill 里写的就是这个过程中走过的弯路和最后留下来的做法。

## 它解决什么

直接让 AI"做个 3D 游戏"，通常会得到一个方块灰模、手感发飘、要自己搭环境才能跑的东西。这个 Skill 让它：

- 开工前先问清参考、范围、素材额度和配乐，而不是闷头写
- 第一天就装好自测工具（逐帧推进、直达关卡的网址参数、F3 诊断面板），能自己验证而不是让你反复试
- 按一套可用的方法做俯视角战斗手感：前摇后摇、顿帧、击退、格挡弹反、敌人轮流进攻
- 避开一批已经踩过的坑：方向键卡住、预设动画把角色甩离原地、泛光过曝、镜头被屋顶挡住、打包后角色缩小等
- 最后交付单个 HTML（约 33MB）、一个先出画面再加载的静态站点，或一个符合小程序类容器限制的离线包

## 安装

```bash
git clone https://github.com/op7418/guizang-game-skill ~/.claude/skills/guizang-game-skill
```

然后直接说"做一个武侠题材的俯视角网页 3D 动作游戏"之类的需求即可。

## 需要准备

- Node.js 18 以上
- 素材生成工具按需准备：Tripo（3D 模型）、即梦（图片与配音）、Suno（配乐）。没有也能做，Skill 会改用免费素材和程序化方案，效果会打折扣

## 说明

Skill 目前只在一个项目上完整走过一遍，另做过一次计划层面的对照测试。它能让方向少走弯路，但不保证成品质量，手感和美术仍然需要人来回试玩提意见。
